No falsas garantías.

NEXUS organiza acciones administrativas. Ninguna interfaz, contraseña local, hash o prueba automática proporciona seguridad completa.

Empieza con los permisos mínimos

Abre el panel como usuario estándar y concede UAC solo a acciones que comprendas. Las confirmaciones ayudan a evitar accidentes; no convierten una acción delicada en una acción inocua.

El modo solo lectura limita operaciones desde la suite. La clave local y DPAPI protegen estado del perfil, pero la propia cuenta, un administrador o código malicioso con esos permisos pueden modificarlo. No son autenticación empresarial ni un sandbox.

Los informes también son datos sensibles

La suite no implementa telemetría. Los inventarios pueden incluir usuario, red y números de serie; los logs contienen actividad y errores. Revisa y anonimiza antes de compartir.

Los registros son editables, no inmutables. La rotación no equivale a un sistema de cumplimiento normativo. Desinstalar conserva datos e informes deliberadamente.

No todo cambio tiene vuelta atrás

  • Convertir FAT32 a NTFS no se revierte desde la suite.
  • Apagar o reiniciar es inmediato tras confirmar; guarda primero tu trabajo.
  • Desactivar el firewall reduce la protección del equipo.
  • Restablecer red puede interrumpir conexiones y requerir reinicio.
  • Deshacer solo cubre un valor interno de Registro, no acciones generales o externas.

Una copia de datos sigue siendo imprescindible. Un punto de restauración puede fallar o estar limitado por Windows y no sustituye una copia de seguridad. Prueba cambios delicados en una VM con instantánea.

Las operaciones externas pueden continuar aunque cierres el panel. En el registro, DISPATCHED significa enviado, no completado.

Aprueba contenido, no una promesa

Los plugins de esta fase son JSON de diagnósticos permitidos. No se ejecutan scripts, DLL o EXE de terceros. Importar no activa ni ejecuta; la aprobación local depende de ID y SHA256. Cambiar el archivo invalida esa aprobación.

Un hash no verifica la identidad del editor. Del mismo modo, los hashes del autoextraíble no autentican el fichero completo si alguien lo reemplaza junto con sus referencias. Verifica origen y firma mediante un canal confiable.

Una web pasiva, no un acceso remoto

Estas páginas no contienen JavaScript, formularios, analítica, fuentes remotas ni cookies propias. Las categorías y preguntas usan elementos nativos del navegador. No se consulta el equipo del visitante.

La CSP por meta limita recursos y código activo. No puede configurar cabeceras como HSTS, frame-ancestors o nosniff; el hosting controla TLS y cabeceras y puede registrar accesos. No se promete un WAF o seguridad absoluta por editar HTML.

La publicación en Pages y las protecciones del repositorio dependen de permisos y despliegue verificados. Consulta la guía de configuración y pendientes ↗.

Ayuda a corregir, sin exponer datos

Para vulnerabilidades usa Security → Report a vulnerability si el repositorio tiene habilitado ese canal. Si no está disponible, solicita un canal privado mediante una incidencia neutra, sin PoC ni información explotable.

Nunca publiques claves, tokens, PFX, contraseñas, inventarios sin anonimizar o logs completos de dominio. No se promete plazo de respuesta ni certificación.
