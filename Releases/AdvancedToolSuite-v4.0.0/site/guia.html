PASO A PASO · SIN COMANDOS OPACOS

Tu primera ejecución.
Con todo el contexto.

Primero revisa. Después verifica. Y solo entonces abre el panel local. Esta guía no ejecuta acciones en tu ordenador.

01 · Requisitos02 · Obtener el fichero03 · Verificar y extraer04 · Abrir el panel05 · Siguientes pasos

01. Comprueba tu entorno

  • Windows 10/11 x64 de escritorio.
  • Windows PowerShell 5.1 y .NET Framework 4.8.
  • Una carpeta propia donde puedas crear un directorio nuevo.

El navegador puede mostrar esta documentación en otras plataformas, pero la aplicación WPF no funciona en Linux, macOS o Server Core. PowerShell 7 no es la plataforma soportada por esta versión.

Empieza como usuario estándar. No necesitas elevar todo el panel. Algunas acciones pedirán UAC cuando las solicites.

02. Obtén y revisa el autoextraíble

Abre el fichero en GitHub desde una revisión de confianza. Allí puedes inspeccionarlo y usar la opción de descarga del archivo. Conserva su nombre: AdvancedToolSuite-v4.0.0-setup.ps1.

Ver el autoextraíble en GitHub ↗

No se afirma que este fichero esté firmado. Un hash comprueba integridad respecto a una referencia confiable; no acredita por sí mismo quién publicó el archivo. No ejecutes una descarga desconocida confiando en que se autentique a sí misma.

Si Windows bloquea la ejecución por una política de tu organización, consulta al administrador. No desactives antivirus, SmartScreen ni políticas corporativas para evitar advertencias.

03. Verifica sin extraer, y luego crea el proyecto

Abre Windows PowerShell en la carpeta donde guardaste el archivo. Selecciona y copia el comando que corresponda; esta web no lo ejecuta ni lo copia automáticamente.

COMPROBAR EL CONTENIDO SIN CREAR ARCHIVOS

powershell.exe -NoProfile -File .\AdvancedToolSuite-v4.0.0-setup.ps1 -ValidateOnly

Si la validación es correcta, puedes extraer el proyecto:

EXTRAER JUNTO AL AUTOEXTRAÍBLE, SIN ABRIR EL PANEL

powershell.exe -NoProfile -File .\AdvancedToolSuite-v4.0.0-setup.ps1

Crea AdvancedToolSuite-v4.0.0 junto al fichero. El destino no debe existir, incluso vacío. Si ya existe, elige otro nombre mediante -Destination; no hay sobrescritura forzada.

OPCIONAL: SIMULAR OTRO DESTINO, SIN CREARLO

.\AdvancedToolSuite-v4.0.0-setup.ps1 -Destination "$env:USERPROFILE\Downloads\ATS-v4-prueba" -WhatIf

Extraer no instala la aplicación. No se crean tareas de Windows, entradas de registro, accesos directos ni plugins activos. No se descargan dependencias.

04. Abre el panel de Windows

En la carpeta creada, abre Tool\Iniciar.cmd o ejecuta desde la raíz del proyecto:

powershell.exe -NoProfile -STA -File .\Tool\AdvancedToolSuite.ps1

El archivo principal incluye XAML e iconos. No necesitas instalar módulos externos para abrir la interfaz. El .bat histórico se conserva como referencia: no incorpora los controles de la nueva UI y no es el lanzador recomendado.

Empieza por un diagnóstico sencillo como Información del sistema. No pruebes apagado, conversión de discos, firewall o cambios de Registro sobre un equipo de producción.
