ANTES DE EMPEZAR

Buenas preguntas.
Respuestas directas.

Leer sobre seguridad →
¿Puedo ejecutar las herramientas desde esta web?

No. Esta web presenta el proyecto y su documentación. Las herramientas funcionan en Windows mediante PowerShell y WPF. No hay acceso remoto al equipo desde el navegador.

¿Es un antivirus o una herramienta de optimización automática?

No. Organiza diagnósticos y accesos administrativos. No promete liberar RAM, acelerar CPU ni garantizar que el equipo esté protegido o libre de fallos.

¿Necesito administrador para abrir NEXUS?

Se recomienda usuario estándar. Algunas acciones solicitan UAC por separado; no hace falta elevar todo el panel. Cancelar UAC no concede permisos.

¿Funciona sin Internet?

El panel y la extracción no necesitan descargar módulos para abrirse. Las pruebas de conectividad y determinadas herramientas de Windows sí pueden usar la red cuando las solicitas.

¿El autoextraíble está firmado?

No se afirma que el fichero incluido esté firmado. Se comprueba integridad mediante hashes, pero estos no autentican al distribuidor. La receta Authenticode necesita un certificado autorizado y verificación real.

¿Se pueden deshacer todos los cambios?

No. Deshacer cubre un valor interno de Registro. No revierte una conversión a NTFS, archivos borrados o cambios externos. Los puntos de restauración tampoco sustituyen copias de tus datos.

¿Qué licencia tiene el proyecto?

MIT, con documentación de derechos y dependencias. Esta licencia no cambia las de herramientas de terceros ni garantiza seguridad. Revisa el texto canónico y los avisos antes de redistribuir.
